# Diploma Online Store

Розробка веб-застосунку інтернет-магазину засобами мови 
програмування JavaScript, бібліотеки React та платформи
Firebase


## Функціональні можливості

- реєстрація та авторизація користувачів;
- перегляд каталогу товарів;
- пошук та фільтрація товарів;
- кошик покупця;
- оформлення замовлень;
- багатомовний інтерфейс;
- адаптивний дизайн.

## Використані технології

- React
- TypeScript
- Vite
- Tailwind CSS
- Node.js
- Express.js
- Drizzle ORM
